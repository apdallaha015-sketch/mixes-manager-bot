بوت Telegram لمتابعة الخطوات — نسخة واجهة فقط

المحتويات:
- bot.py: كود البوت
- requirements.txt: مكتبات Python المطلوبة

مهم:
- هذه النسخة تعرض الخطوات وتتابعها يدويًا فقط.
- لا تنفذ تحويلات ميكسات أو تغيير باقات، ولا تتصل بواجهات اتصالات الداخلية.
- يلزم API رسمي ومصرح به لتنفيذ أي عمليات على حساب اتصالات.
- لا تشارك BOT_TOKEN مع أي شخص. بما أن التوكن السابق ظهر في صورة، استخدم التوكن الجديد الذي أصدرته عبر BotFather.

تشغيل على استضافة Python:
1) ثبّت المكتبات: pip install -r requirements.txt
2) عيّن متغير البيئة BOT_TOKEN إلى التوكن الجديد (لا تكتبه في ملفات عامة).
3) اختياريًا عيّن ADMIN_ID إلى رقم Telegram user ID الخاص بك لقصر الاستخدام عليك.
4) شغّل: python bot.py

على Android فقط:
يمكن استخدام بيئة Python مثل Termux، لكن البوت قد يتوقف عند إغلاق التطبيق/النظام. للاستمرار 24/7 استخدم استضافة موثوقة.
